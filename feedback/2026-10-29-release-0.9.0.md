## Slik gir du ut (når du er klar)
1. Slå sammen `claude/ukesrapport-2026-10-28` til `main` (PR eller merge).
2. `git checkout main && git pull`
3. `git tag v0.9.0 && git push origin v0.9.0`
4. Følg «Release AddOn» under Actions på GitHub. Den kjører tester, pakker og laster opp til CurseForge og GitHub Releases.
5. Vil du teste først: bruk `v0.9.0-beta1` (lastes opp som beta, vanlige brukere får den ikke).

- Feil oppdaget etter publisering: marker filen som arkivert på CurseForge og gi ut v0.9.1.
