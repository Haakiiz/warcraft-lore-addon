## Emerald Dragons (asked specifically)
Emeriss (14889) and Lethon (14888) are permanent world bosses in Classic: wiki `Emeriss_(Classic)` / `Dragons_of_Nightmare_(Classic)`: "These dragons were world spawns located in Duskwood (Twilight Grove), the Hinterlands (Seradane), Feralas (Dream Bough), and Ashenvale (Bough Shadow)"; patch changes "Patch 1.8.0: Added", "4.0.3a: Removed". Not event-only: the event versions are the separate "(Anniversary)" NPCs (retail 13th Anniversary), which these IDs are not. Both PASS on identity/lore; `coords` was empty, filled with 90.3, 40.1 (Bough Shadow, Ashenvale; wiki Emeriss page `{{coords|90.3|40.1|Ashenvale (Classic)}}`), wiki-sourced, Wowhead unconfirmed.
